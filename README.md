# Ecom Project

This project is a simple ecommerce landing page built with HTML and CSS.

## Project Overview

The website includes:
- a navigation bar
- a hero section
- feature highlight cards
- a product catalog section
- basic responsive styling for mobile and desktop

## Folder Structure

- `index.html` - main page markup
- `style.css` - styling for the layout and components
- `assets/` - image assets used by the project
- `info/` - notes and supporting files
- `builds/` - build output folder

## How to Run

Open `index.html` in a browser, or run a local server:

```bash
cd "D:\Sujay\Resources\Ecom"
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes

This is a basic starter ecommerce UI and can be expanded with more pages, product interactions, login forms, and cart functionality.
